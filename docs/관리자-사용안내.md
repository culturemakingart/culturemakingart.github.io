# 문화제작예술소 관리자

주소: https://culturemakingart.kr/admin/

1. culturemakingart@gmail.com으로 로그인 링크를 요청합니다.
2. 받은 메일의 링크를 열어 로그인합니다. 대시보드 계정 로그인과 사이트 관리자 로그인은 별개입니다.
3. 홈·단체 소개·프로그램·프로젝트 메뉴에서 항목을 선택하고 편집합니다.
4. 사진을 올리면 URL이 자동 입력됩니다. 사진 설명도 입력한 뒤 저장합니다.
5. 프로그램·프로젝트는 공개 체크를 해제하면 목록과 상세에서 숨겨집니다. 저장하면 바로 반영됩니다.
6. 문의함에서 접수 내용을 확인하고 메일로 답변합니다. 답변 완료 상태 변경은 메일을 자동 발송하지 않습니다.
7. 작업을 마치면 로그아웃합니다.

## 보관
문의는 자동 삭제하지 않습니다. 로그인한 관리자만 조회할 수 있습니다. 삭제 요청은 운영자가 별도로 처리합니다. 문의함은 최근 200건을 표시하며, 예전 데이터가 자동 삭제되는 것은 아닙니다.

## 홈·단체 소개 편집
- 홈 메뉴를 누르면 바로 편집할 수 있습니다. 메인 이미지는 파일을 올리거나, 사진이 있는 공개 프로그램·프로젝트에서 고릅니다.
- 프로그램·프로젝트 사진을 선택해 연동하면 해당 항목의 대표 사진 변경을 홈에서도 따라갑니다. 비공개된 항목의 경우 마지막 사진을 유지합니다.
- 단체 소개에서는 소개 글, 지향점, 활동 방식, 함께하는 사람들, 연혁, 아래 안내 문구를 각각 수정합니다.
- 사람 추가/빼기와 위로/아래로 버튼으로 구성원과 순서를 정합니다. 구성원별 사진도 올릴 수 있습니다.
- 연혁 추가/빼기로 연도·활동명·기관·설명을 편집합니다.
- 변경 취소는 아직 저장하지 않은 내용을 되돌립니다. 변경 내용 저장을 누르면 사이트에 반영됩니다.

## 운영 구분
- 내용과 사진: 관리자에서 수정
- 배치·색·디자인: 최신 코드로 클로드와 수정 후 배포
- 원본 ZIP은 최신 파일이 아닙니다. 최신 기준은 GitHub main입니다.
- tools/build.py는 이전 초안 생성기이며 최신 사이트 제작에 사용하지 않습니다.
- 새 관리자 추가는 서버의 관리자 명단을 수정해야 합니다. 공개 회원가입만으로는 관리자 권한을 얻을 수 없습니다.
- 기본 이메일 발송 서비스에는 발송량 제한이 있으므로 로그인 링크가 오지 않을 때 반복 요청하지 말고 잠시 기다리세요.

## 검증 상태
공개 콘텐츠 조회, 비로그인 문의 조회 차단, 비로그인 콘텐츠 편집 권한 없음, 프로그램 검색과 상세 표시를 확인했습니다. 관리자 이메일 로그인, 기존 프로그램 저장, 사진 업로드, 테스트 문의 접수·조회·상태와 메모 변경 및 새로고침 후 유지까지 확인했습니다.
# 프로그램 상세 항목 편집

프로그램 → 새 항목 추가에서 기본 정보와 9개 항목을 입력합니다. 기존 프로그램도 같은 화면에서 수정합니다.

- 대표 사진은 목록과 상세 상단에 표시됩니다. 현장 사진(최대 4장)과 결과물 사진(1장)은 따로 업로드합니다.
- 활동 단계는 2~4개로 작성하고, 운영 실적은 필요한 만큼 추가합니다. 위·아래 버튼으로 순서를 변경할 수 있습니다.
- 대상·최소/최대 인원·진행 방식, 맞춤 조정, 협업처/단체 준비 사항, 비용 안내를 각각 작성합니다.
- 사이트에 공개를 선택하고 변경 내용 저장을 누르면 상세페이지에 반영됩니다. 비용 안내 옆에는 문의 버튼이 표시됩니다.
- 비공개 상태로 저장해두고 나중에 내용을 보완할 수 있습니다. 빈 상세 항목은 공개 페이지에서 생략됩니다.

# 관리자 비밀번호 로그인

관리자 페이지의 ‘비밀번호 설정·변경’을 열고 새 비밀번호를 두 번 입력해 저장합니다. 처음 설정할 때 로그인되어 있지 않다면 로그인 화면의 ‘처음 이용하거나 비밀번호를 잊으셨나요?’에서 이메일 링크로 한 번 접속하세요.

그다음부터 이메일과 비밀번호로 로그인할 수 있습니다. ‘이 기기에서 로그인 유지’를 선택하면 브라우저를 닫아도 로그인 상태가 유지됩니다. 비밀번호 자체는 브라우저 저장소에 저장하지 않습니다. 공용 기기에서는 로그인 유지를 해제하고 사용 후 로그아웃하세요.
