# 현재 운영 사이트 디자인 수정 안내

이 압축파일은 https://culturemakingart.kr 에 배포한 최신 통합 소스입니다. 관리자 페이지와 콘텐츠 연결 코드가 포함되어 있습니다. 과거 ZIP 대신 이 파일을 기준으로 작업해주세요.

- DungGeunMo와 브랜드 팔레트를 유지하고 요청한 디자인만 수정해주세요.
- 홈은 소개·대표 사진·버튼 구성을 유지해주세요.
- 관리자 로그인, 비밀번호 설정, 로그인 유지, 문의 저장, 이미지 업로드 기능을 유지해주세요.
- HTML id, 폼 name, data 속성, 스크립트 로딩 순서를 유지해주세요. site-api.js, site-content.js, about-content.js, content-order.js와 admin 폴더의 기능을 제거하거나 정적 내용으로 대체하지 말아주세요.
- 파트너 작가와 프로그램은 가나다순, 프로젝트는 최신 연도순으로 자동 정렬됩니다. 정렬 로직을 유지해주세요.
- 단체 소개 관리 화면은 단체 소개 / 함께하는 사람들 + 파트너 작가 / 연혁의 세 탭입니다. 파트너 작가는 사진 입력란이 없고, 연혁은 활동 설명 입력란이 없습니다.
- 실제 운영 콘텐츠와 문의 내역은 Supabase에 별도로 저장됩니다. 이 파일은 소스 코드이며 데이터베이스 백업이 아닙니다. 관리자에서 저장한 내용을 샘플 텍스트로 덮어쓰지 말아주세요.
- tools/build.py는 과거 생성기입니다. 실행해 현재 HTML과 연결 기능을 덮어쓰지 말아주세요.
- 디자인 수정은 PC와 모바일 모두 확인하고, 변경 목록과 수정 파일을 원래 경로 구조의 ZIP으로 전달해주세요.
- 로그인·DB·배포·도메인은 변경하지 말아주세요. 수정본은 Codex에서 기능 확인 후 배포합니다.
